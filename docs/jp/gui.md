# GUIチュートリアル

[English](../en/gui.md)

1. 起動後、Cobottaでは指定範囲のP変数を実機から読み込みます。その他のデバイスは既定JSONを読み込みます。
2. 「現在位置を取得」でロボットの座標を取得します。
3. 指定P番号、または一覧で選択した1行に対して、**取得した現在位置**を書き込みます。実機モードでは確認ダイアログに注意してください。
4. 一覧の右クリックで「現在位置を書き込む」「0クリア」「一覧から削除」を選択します。Ctrl/Command・Shiftで複数行を選択して、0クリア・削除ができます。
5. **0クリア**は値を `[0, 0, 0, 0, 0, 0, -1]` に変更します。**一覧から削除**は行を取り除く操作であり、Cobotta内部のP変数は削除しません。
6. JSONの読込・保存はファイルダイアログで任意のファイルを選択できます。初期表示は起動時の `JSON_FILE` です。
7. 終了時に未保存の変更があると、保存／保存せず終了／キャンセルの確認が出ます。Cobottaの場合は実機同期とJSON保存の扱いを確認してください。

**注意:** Cobottaへの書き込みは操作時点で実行されます。終了時に「保存しない」を選択しても、実機に実行済みの書き込みは元に戻りません。通信中は終了処理が待機する場合があります。
