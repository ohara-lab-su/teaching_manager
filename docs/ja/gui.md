# GUIチュートリアル

以下の表は同梱例の、`methods` を省略した場合の動作です。

1. 起動後、Cobottaでは指定範囲のP変数を実機から読み込みます。その他のデバイスは既定 JSON を読み込みます。従来モードの番号入力は P0〜P999 です。JSON を読み書きする `RobotVarManager` にはこの上限はありません。
2. 「現在位置を取得」でロボットの座標を取得します。
3. 指定P番号、または一覧で選択した1行に対して、 **取得した現在位置**を書き込みます。実機モードでは確認ダイアログに注意してください。
4. 一覧の右クリックで「現在位置を書き込む」「0クリア」「一覧から削除」を選択します。Ctrl/Command・Shiftで複数行を選択して、0クリア・削除ができます。
5. **0クリア**は値を `[0, 0, 0, 0, 0, 0, -1]` に変更します。 **一覧から削除**は行を取り除く操作であり、Cobotta内部のP変数は削除しません。
6. JSONの読込・保存はファイルダイアログで任意のファイルを選択できます。ファイルダイアログの初期パスは起動例の `JSON_FILE` です。
7. 終了時に未保存の変更があると、保存／保存せず終了／キャンセルの確認が出ます。COBOTTA で「保存」を選ぶと、一覧中の変更点を装置側に同期してから、一覧を既定 JSON に保存します。

**注意:** Cobottaへの書き込みは操作時点で実行されます。終了時に「保存しない」を選択しても、実機に実行済みの書き込みは元に戻りません。通信中は終了処理が待機する場合があります。

起動例が `methods` を指定して接続先の教示点を使う場合、起動時に存在する P 点をすべて表示します。P 番号の入力に固定上限はありません。一覧の右クリックメニューからは教示と 0 クリアを実行できます。JSON 保存は接続先が担います。
