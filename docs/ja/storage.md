# JSON管理・実機同期・終了時の動作

| 操作         | CobottaCtrl                | その他のデバイス           |
|--------------|----------------------------|----------------------------|
| 起動時       | 実機P変数を取得            | JSONを取得                 |
| 現在位置     | DeviceProxyから取得        | DeviceProxyから取得        |
| ティーチング | 実機に書き込み、読み戻し   | JSONを更新                 |
| 0クリア      | 実機に書き込み、読み戻し   | JSONを更新                 |
| 一覧削除     | 実機値は維持               | JSONからも削除             |
| JSON保存     | 選択したファイルへ書き出し | 選択したファイルへ書き出し |

## JSONの形式

```json
{
  "P0": [
    0,
    0,
    0,
    0,
    0,
    0,
    -1
  ],
  "P1": [
    100,
    200,
    300,
    0,
    0,
    0,
    -1
  ]
}
```

上記は **形式例**であり、各ロボットの座標配列長や末尾値の意味を保証するものではありません。Modelは `P`
と数字からなるキーだけを読み込みます。JSONルートはオブジェクトである必要があります。

終了時に保存を選択すると、Cobottaでは一覧と内部値の差を同期し、既定JSONへ保存します。一覧から消したP番号は実機から消しません。通信・保存に失敗した場合は、実機とJSONの両方が更新済みとは限りません。書き込み前にバックアップしてください。
